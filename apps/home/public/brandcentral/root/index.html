brand architecture

hierarchy
the model

root operates a branded house architecture — a single operating system powering distinct market-facing brands. root is the infrastructure layer; content co-op and astro cleaning services are the surface layer. think alphabet governing google and waymo, or lvmh governing louis vuitton and dior.

key distinction: root is never visible to end-users. it’s the operating system — the brands are the apps. customers interact with content co-op or astro cleaning services, never with root directly.

voice & naming

brand voice
conventions
a
logo lockup is lowercase — the root logo wordmark renders in lowercase. this is a logo treatment only, not a system-wide text convention.
-
product naming — canonical names: “Co-Script”, “Co-Cut”, “Co-Deliver”. use standard capitalization in all running text and UI labels.
r
system naming — use normal casing in text: “Root System”. the lowercase “root” is reserved for the logo wordmark only.
.
tone — minimal, precise, technical. say what needs to be said and nothing more.
guidelines
do
  • use normal capitalization in all text
  • be direct
  • technical precision over marketing fluff
  • use the hyphen in co-product names (Co-Script, Co-Cut)
  • reference the system as “Root System”
  • use monospace for technical references
  • reserve lowercase for the logo wordmark only
don’t
  • no all-lowercase body text (that’s a logo treatment, not a writing rule)
  • no exclamation marks
  • no buzzwords
  • no “innovative”, “revolutionary”, “cutting-edge”
  • no emoji in product copy
  • no sentence fragments that sound like ads
