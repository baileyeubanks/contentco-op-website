# Asset Library

BRAND owns the approved shared asset library for ACS, Content Co-op, and common brand-support files.

## Live folders

- `assets/acs/logos/png`: approved ACS logo exports currently present in this repo
- `assets/acs/icons/png`: ACS favicon and manifest icon set
- `assets/acs/exports`: document-safe signatures and export variants
- `assets/acs/photography/jpg`: approved ACS photography library
- `assets/acs/motion/mp4`: approved ACS motion library
- `assets/cco/logos/png`: approved CCO logo exports currently present in this repo
- `assets/cco/logos/optimized`: downscaled CCO logo variants for browser previews and lightweight consumers
- `assets/cco/avatars/jpg`: approved Bailey portrait assets
- `assets/cco/exports`: document-safe signatures and export variants
- `assets/cco/photography/jpg`: approved CCO photography library
- `assets/cco/motion/mp4`: approved CCO motion library
- `assets/fonts/gotham-condensed`: supporting font files currently kept in-repo

## Reference rules

- If a doc points at a file that no longer exists, update the doc rather than silently recreating an unapproved asset.
- `docs/asset-authority.md` and `docs/asset-inventory.csv` are the authority maps for keep/migrate/archive decisions.
- `docs/browser-preview.html` is the main visual review surface for current assets.
- `docs/archive` and `docs/reference` hold historical previews and source material, not new canonical assets.
